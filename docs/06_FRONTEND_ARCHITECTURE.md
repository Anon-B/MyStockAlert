- /

## Dashboard
Show:
- Thai portfolio summary
- US portfolio summary
- Current value
- P/L amount and percentage
- Watchlist movement
- Recent alerts
- Service status

## Portfolio Page
- Holdings table
- Add holding
- Edit holding
- Delete holding
- Current price and P/L

## Watchlist Page
- Watchlist table
- Current price
- Price change
- Upper threshold
- Lower threshold
- Alert status
- Add, edit, delete
## Settings Page
- LINE
- Market and alerts
- Portfolio
- Display
- System

## UX Rules
- Responsive layout
- Confirm destructive actions
- Clear loading and error states
- Show stale-data indicators
- Mask secrets
- Avoid exposing provider credentials
